# 智慧社区居民端 - HTML 高保真原型

> 版本：v1.0  
> 整理日期：2026-06-03  
> 状态：✅ 原型阶段完成（21 个页面 + 公共资源）

## 📖 简介

本目录是智慧社区居民端的**高保真 HTML 原型**，用于在正式开发前验证产品形态、交互细节和视觉风格。所有页面均可在浏览器中直接打开查看，模拟真实微信小程序的体验。

详细方案见同目录 `../docs/` 下的两份文档：
- `智慧社区居民端-原型方案.md` —— 原型设计方案
- `智慧社区居民端-完整实施方案.md` —— 完整技术方案

## 🚀 预览方式

### 方式一：本地 HTTP Server（推荐 ✅）

```bash
cd 原型/
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`

### 方式二：VSCode Live Server
右键 `index.html` → "Open with Live Server"

### 方式三：直接双击 HTML
由于已用 emoji 替代 iconfont（规避 file:// 跨域），可双击 `login.html` 直接打开。

> 推荐使用方式一或方式二，体验更接近真实预览。

```
                    ┌─ 登录 (login.html)

   ┌───────────── index.html (首页) ─────────────┐
   │   Tab: 首页/服务/消息/我的                   │

   │   推荐活动  ─→  activity-detail.html         │
   │   最新通告  ─→  notice-detail.html           │
   └──────────────────────────────────────────────┘
        │           │         │         │
   service.html   message.html  profile.html
        │           │
        ↓           ↓
   各模块首页     消息详情

模块内部跳转（举例 - 活动模块）：
   activity-list.html → activity-detail.html（点击活动卡片）
   activity-detail.html → activity-list.html（顶部返回）
```

## ⚠️ 注意事项

1. **数据为 Mock**：所有数据为静态展示，无后端交互
2. **商户小程序跳转**：原型中点击后弹 Toast 提示，**不会真跳**
3. **拨打电话/地图**：弹窗模拟，**不会真调起**
4. **登录/注册**：默认直接进入首页，**无真实登录**
5. **图标为 emoji**：不同系统可能显示略有差异
6. **响应式**：固定 375px 宽度，**不做 PC 适配**
